# My Personal Website

Welcome to my personal portfolio website! This is a modern, responsive website built with HTML and CSS.

## Features

- 🎨 Modern design with gradient backgrounds
- 📱 Fully responsive on all devices
- 🌐 Bilingual support (Urdu/English)
- ⚡ Fast and lightweight

## Live Demo

Visit: https://AliTechHub-leb.github.io

## How to Customize

1. Edit `index.html` to change:
   - Your name and title
   - Navigation links
   - About section content

2. Modify the `<style>` section for colors and fonts

## Getting Started

Clone this repository and open `index.html` in your browser.

```bash
git clone https://github.com/AliTechHub-leb/AliTechHub-leb.github.io.git
cd AliTechHub-leb.github.io
```
